Income prediction on census data

This project predicts whether a person's income exceeds $50K a year from census data, and which census features push it higher. It is a binary classification covering data cleaning, wrangling, feature correlation, model training and evaluation.

1. Exploring the data

The features and the target were merged into one dataframe. The initial dataframe had 48,842 rows before cleaning.

2. Cleaning the target column

At first glance the target column had mismatched labels: some values carried a trailing period. I aligned them so the column has just two labels.

df['income'] = df['income'].replace(['<=50K.', '>50K.'], ['<=50K', '>50K'])
df['income'].value_counts()

4. Feature scaling and correlation

I scaled the features with a standard scaler, then plotted a correlation heatmap to spot highly correlated features.

5. Training the models

The approach was to train several models and pick the best performer on accuracy and recall.

I trained four classifiers that are common choices for binary classification: logistic regression, random forest, decision tree and XGBoost. Since this was a simple project, I did no hyperparameter tuning and used the default settings for each model.

The results for each algorithm:

6. Evaluating the models

XGBoost was the best performer on accuracy and recall.

7. Which features matter

I calculated feature importance to see which census features carry the most weight.

Relationship, capital gain, education number, marital status and capital loss are the features that most influence income.

8. Conclusion

I identified the features that could be significant in determining a higher salary range in this population dataset. Next steps would be to engineer more features and to apply hyperparameter tuning to improve the model.
